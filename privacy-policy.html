Privacy Policy

Last updated: August 23, 2026

"The Fine Print Auto-Poster" ("the App") is a private, single-user automation tool operated by Ajay Roy. It connects to exactly one TikTok account ("The Fine Print") via TikTok's official Content Posting API, and is not offered to or used by any other person or account.

1. What data the App accesses

The App requests only the minimum TikTok API scopes needed to publish content and identify the connected account, such as basic profile information (username, display name) and the ability to publish photo/video posts. The App does not access followers, direct messages, analytics beyond what TikTok's API exposes for the connected account, or any data belonging to other TikTok users.

2. What data the App stores

The App stores the OAuth access token and refresh token issued by TikTok for the connected account, so it can publish posts without requiring a fresh login each time. These tokens are stored privately by the operator and are not shared with any third party.

3. What the App does not do

The App does not sell, rent, or share any data with third parties. It does not use TikTok data for advertising, profiling, or any purpose beyond publishing the operator's own content to their own account.

4. Data retention and deletion

Stored tokens are retained only as long as the App remains connected to the account. The operator can revoke the App's access at any time from TikTok's account settings, which immediately invalidates the stored tokens.

5. Contact

Questions about this policy, or requests to review or delete stored data, can be directed to: ajay.roy@gmail.com
